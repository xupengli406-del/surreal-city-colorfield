# 场景卡与色相矩阵

多图城市系列在生成前使用本文件。目标是把创作判断放在前面，避免九张图生成完才发现全部是同一种蓝天或颜色只落在小物件上。

## 2. 单张场景卡

每张填写一张：

```text
地点：
现实锚点：3 秒内必须看见什么？
不可遮挡：哪些轮廓或结构不能被巨物挡住？
可着色区域：天空 / 水面 / 墙体 / 道路 / 植被 / 其他
原生色：色源 1、色源 2、色源 3
地点语义：结构 / 功能 / 历史 / 大众记忆
唯一巨物：
连接句：[建筑/区域] extends into / becomes / continues as [巨物]
主导动势：
小元素：巨物的哪些同源碎片可形成 3–5 个梯度？
白色手绘线：沿哪条动势出现 2–3 条？
强度等级：高 / 中 / 安静 / 夜景
```

### 场景卡自检

- 巨物能否从地点解释，而不是从参考图照搬？
- 大色域能否画出明确边界？
- 原图若去色，地标是否仍然可辨认？
- 巨物是否会遮住最重要的识别结构？

### 判断整组是否成立

把主色写成一行：

```text
橙蓝 → 蓝粉 → 蓝金 → 青 → 砖红金 → 黄蓝 → 靛蓝绿 → 紫粉 → 青红
```

这不是固定答案，只是一个能看出节奏的例子。检查：

- 是否连续三张都是相近蓝色天空？若是，改变其中一张着色区域或使用情绪反转。
- 是否每张都同样鲜艳？若是，指定 1–2 张安静页。
- 是否只有巨物有颜色、背景全是暖白？若是，至少让部分图片把天空、水面或墙体变成大色域。
- 是否单张出现 4 种以上抢眼颜色？若是，删到 1–2 组主色。
- 是否有至少四个色相家族贯穿整组？不足时从原图色、材质色或情绪反转中补足。

## 4. 彩色面积与饱和度的实用判断

不要把“鲜艳”理解为整图饱和度拉高。城市拼贴通常需要大量黑白现实层来托住彩色区域。

- 眯眼看时，彩色区域应首先形成一个或两个清楚的大形，而不是散成小点。
- 当现实层以黑白为主时，彩色区域大约占画面 20%–55% 往往更容易形成冲击；这是诊断区间，不是硬指标。
- 彩色区域本身应高纯度；黑白建筑、暖白纸面和夜景黑色不应被误算成“颜色不够”。
- 小元素必须复用主色或辅色，不为增加颜色数量而另开新色。

## 5. 九张系列的强弱排法

一种稳定的排法：

```text
高冲击 → 中强度 → 夜景停顿
安静页 → 中强度 → 情绪反转高冲击
中强度 → 高冲击 → 高冲击收束
```

联系表里如果每张都在喊，删色或增加黑白面积；如果只有第一张有冲击，把中后段至少两张的彩色区域扩大到天空、水面或墙体。
